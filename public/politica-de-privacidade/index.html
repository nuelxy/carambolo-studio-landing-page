Política de Privacidade

Esta Política de Privacidade explica como o Carambolo Studio coleta, utiliza e protege os dados fornecidos pelos usuários por meio deste site.

1. Dados coletados

Poderão ser coletados dados como nome, WhatsApp, cidade/estado, perfil do Instagram, tipo de projeto e informações adicionais enviadas voluntariamente pelo usuário.

2. Finalidade da coleta

Os dados são utilizados para atendimento inicial, avaliação do projeto, envio de resposta, elaboração de orçamento e continuidade da comunicação comercial.

3. Compartilhamento de dados

Os dados não serão vendidos. Poderão ser compartilhados apenas quando necessário para viabilizar o atendimento, cumprir obrigação legal ou proteger direitos do Carambolo Studio.

4. Armazenamento e segurança

O Carambolo Studio adota medidas razoáveis para proteger as informações fornecidas, evitando acesso não autorizado, perda, alteração ou divulgação indevida.

5. Direitos do titular

O usuário poderá solicitar acesso, correção ou exclusão dos seus dados pessoais, nos termos da Lei Geral de Proteção de Dados Pessoais.

6. Contato

Para solicitações relacionadas a dados pessoais, utilize os canais oficiais de atendimento do Carambolo Studio.
